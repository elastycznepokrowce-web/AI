# Reklama: Tester, którego nie można zwolnić

Gotowy film reklamowy do Facebooka i Instagrama: 15 sekund, format 1:1, 1080 × 1080 pikseli. Zawiera muzykę, napisy i adres www.elastycznepokrowce.pl.

Pliki znajdują się w katalogu `reklama-psiak`:

- `reklama-tester-1x1.mp4` — film reklamowy.
- `okladka.jpg` — okładka.
- `tekst-reklamy.txt` — propozycja tekstu posta.

Aby pobrać film z GitHub, otwórz `reklama-psiak/reklama-tester-1x1.mp4` i kliknij **Download raw file** (ikonę pobierania w prawym górnym rogu widoku pliku).

## Podgląd v2 — logo i kolory firmowe

Plik `reklama-psiak/reklama-tester-brand-v2-podglad.mp4` zawiera oryginalne logo z dokumentu EP.pl_final_v2.pdf oraz firmową czerwień #D02327, biel i czerń. Format 1080 × 1080, 15 sekund, wesoły podkład instrumentalny.

Typografia poza oryginalnym logo jest tymczasowa: PDF zawiera obrysy logo, ale nie pliki czcionek. Końcowy eksport z Brandon i Gilroy wymaga dostarczenia ich plików OTF/TTF. Podgląd nie jest końcową wersją typografii.
